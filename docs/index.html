The friction

You ask Claude for an HTML mockup. It generates something close. You type "make the hero bigger and the CTA orange." Then "actually move that section up." Then "no, smaller headline." Twenty messages in you're describing pixels with words.

→ make-interactive turns that into clicking.
How it works

Three steps. One coherent loop.

Run the skill on any HTML file. Drop comments in the browser. Claude does the rest, in real time.

1

Launch

In Claude Code, point the skill at any HTML file. A local server boots and opens in your browser.

/make-interactive mockup.html
2

Comment

Toggle comment mode. Pin any element or highlight any text. Write what should change. Pick a quick-action if you want.

3

Watch Claude edit

The skill reads your comments, edits the source HTML, the page hot-reloads. Pins persist. Iterate as long as you want.

Inside

A designer's whole feedback loop, packed in one skill.

Built by a Senior Product Designer who got tired of typing pixel changes into a chat.

📌

Pin mode

Click any element. Drop a comment anchored to it. Multiple pins on the same element cascade horizontally like Figma threads — never stacked on top of each other.

✏️

Highlight mode

Select any text. Comment on a sentence, a word, a paragraph. Perfect for PRDs, reports, longform content — not just visual mockups.

⚡

Designer quick-actions

Rewrite. Tighter. Clearer. Variants. Copy-only. Layout-only. Add motion. Ask, don't edit. Eight chips that shape Claude's interpretation without you spelling it out.

📦

Batch workflow

Drop a pin. Drop another. Drop five. Hover Send to preview every draft, delete the ones you changed your mind on, submit them as one coherent set.

🔄

Live reload

Server-Sent Events push a refresh the moment Claude edits the source. Pins persist across reloads, restored from a JSON queue. No 'click refresh' moments.

⏱️

History + revert

Every file change creates a snapshot. The sidepanel lists them with Claude's applied notes. One click to roll back — and reverts are themselves reversible. Experiment fearlessly.

Install

One command. No npm. No pip.

Python 3.7+ and Claude Code required. Everything else lives in your ~/.claude dir.

curl -fsSL https://raw.githubusercontent.com/seant-ctrl/make-interactive/main/install.sh | bash

Then restart Claude Code. The /make-interactive command is now available across all your projects — point it at any HTML file and start iterating.
